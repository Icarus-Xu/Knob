## 硬件路线

1. **最小硬件调试**（`旋钮-最小硬件调试方案.md`）：ESP32-S3 + GC9A01 圆形屏 + EC11 编码器（约 ¥65~100，**已下单**），本地跑通「屏显 UI + 旋钮切功能 + 按压确认 + 本地模拟回显」，暂不连车机。
2. **接 BLE HID**：复用 X-Knob 的 `lib/ble_kb`，把旋转/按压上报为键盘事件。
3. **接真实车况回显**：GATT Write Characteristic，App 把 BYDAUTO 读到的状态写回旋钮屏。
4. 产品化：锂电池 + 3D 外壳。

## 风险（已无兜底路线）

无障碍模拟点击兜底方案已于 2026-08-28 弃用，项目全押官方签名路线，以下三条任一不成立都会阻断车控：

1. **拿不到车机厂商签名** → 车控直接告吹（签名申请进行中）。
2. **包名白名单**（推断，未验证）→ 即便签名到手，`cn.icarus.knob` 若不在服务端白名单内仍会被拒。装车第一件事就验这个。
3. **车机限制动态加载 DEX** → 若被限制，壳+DEX 的免重签收益归零，退回"每次改动都重签"。

> 三条风险都只能等签名版装车才能实测，所以在此之前应把无需签名的阶段 4/5（蓝牙通路 + 按键映射）做完，避免空等。
